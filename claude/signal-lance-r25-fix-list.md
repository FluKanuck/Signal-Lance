# Signal Lance: Round 25 fix list

**Started:** 2026-10-08 from the QA panel batch `r24-core-1008` (report `claude/signal-lance-qa-r24-core-1008.md`, page https://claude.ai/artifact/Wma3pSVagK986FfBHrV9NX) and the R24 report's Parked list. Same routine as R18–R24: build these alongside the round's change, ship them in the round's builds, and note each one in the report. Jamie may add rows while he plays (screenshots as `claude/fixlist/r25-NN-k.png`, cropped to the game window).
**Why this list:** the Godot port copies the rules seed for seed. A rule bug that is still in the game when we write the golden logs goes into Godot too. So this list fixes rule bugs and rule-feedback gaps only. Map clutter, labels, the camera and the HUD layout are **not** on it, because Godot rebuilds the view.
**Re-check:** the QA panel (sl-qa, core preset) runs on the final build with the same seeds.
